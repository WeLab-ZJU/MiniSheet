# ESP32 Firmware

This directory contains the ESP32 firmware for stepper motor control in the MiniSheet system.

## Setup and Usage

1. Install [Visual Studio Code](https://code.visualstudio.com/) and the [PlatformIO IDE extension](https://docs.platformio.org/en/latest/integration/ide/vscode.html).
2. Open this `ESP32` directory as a project in VS Code.
3. Connect the ESP32-S3 development board to your computer via USB.
4. Open `src/main.cpp` and upload the firmware using PlatformIO.

PlatformIO will automatically install the required toolchain and dependencies specified in `platformio.ini`.

For more information, see the [PlatformIO IDE for VS Code documentation](https://docs.platformio.org/en/latest/integration/ide/vscode.html) and the [ESP32-S3-DevKitM-1 board documentation](https://docs.platformio.org/en/stable/boards/espressif32/esp32-s3-devkitm-1.html).
